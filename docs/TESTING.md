# Auto Clicker 3.0.1 — Windows 11 Test Plan

## 1. Build gate

1. Распаковать ZIP в путь с пробелами и кириллицей.
2. Запустить install-and-build.bat.
3. Проверить exit code self-test 0.
4. Проверить portable ZIP и Setup.exe.
5. Установить Setup без прав администратора.

## 2. Навигация и repaint

1. Переключить Управление → Хоткеи → Overlay → Управление 30 раз.
2. Повторить через Настройки.
3. Убедиться, что видна ровно одна страница.
4. Быстро провести мышью по навигации.
5. Проверить отсутствие дублирования текста и белых контролов.
6. Проверить resize, minimize, restore.

## 3. DPI

1. Проверить 100%, 125%, 150%, 175%, 200%.
2. Перетаскивать окно между мониторами с разным DPI.
3. Проверить текст, sliders, combo popups и hit targets.
4. Убедиться, что окно остаётся внутри экрана.

## 4. Независимые интервалы

1. Установить LMB 10 мс, RMB 3 мс.
2. Запустить оба канала.
3. Убедиться, что RMB CPS выше LMB.
4. Изменять каждый интервал во время работы.
5. Проверить границы 1 и 1000 мс.
6. Перезапустить и проверить сохранение.

## 5. Mouse 4/5 simultaneously

1. LMB = Mouse 4 Hold.
2. RMB = Mouse 5 Hold.
3. Удерживать Mouse 4.
4. Не отпуская, удерживать Mouse 5.
5. Отпустить Mouse 4 — RMB продолжает работать.
6. Отпустить Mouse 5 — оба остановлены.
7. Повторить с двумя подключёнными мышами.

## 6. Hold/Toggle/Press

Для каждого канала:

1. Hold запускается на down и останавливается на up.
2. Toggle меняет состояние только на новый физический down.
3. Press отправляет один клик без repeat.
4. Сменить режим во время работы — канал останавливается.
5. Скомбинировать LMB Toggle и RMB Hold.

## 7. Modifier compatibility

1. Удерживать W + Space + Shift.
2. Проверить Mouse 4/5: лишние модификаторы не мешают срабатыванию.
3. Назначить Ctrl + Mouse 4.
4. Отпустить Ctrl раньше Mouse 4 — Hold должен остановиться.

## 8. Передача событий в игру

1. Назначить Mouse 4, Mouse 5 и клавиатурную комбинацию.
2. Убедиться, что все исходные down/up проходят в тестовое окно и Minecraft.
3. Проверить одновременный LMB/RMB Hold.
4. Убедиться, что только диалог захвата временно блокирует записываемое событие.

## 9. Hook Studio

1. Захватить клавишу, Mouse 3/4/5 и Ctrl + Mouse 4.
2. Отменить через Esc.
3. Попытаться назначить конфликтующий хоткей.
4. Запустить Test и убедиться, что клики не отправляются.
5. Проверить зелёный hook status.

## 10. Panic/release

1. Запустить оба канала на 1 мс.
2. Нажать F12.
3. Оба состояния сразу OFF.
4. Проверить отсутствие зажатых LMB/RMB.
5. Повторить при Mouse 4+5 Hold.
6. Закрыть приложение во время работы.
7. Заблокировать Windows во время работы.

## 11. Settings resilience

1. Сохранить настройки и проверить .bak.
2. Повредить основной JSON.
3. Перезапустить и проверить recovery message.
4. Проверить .corrupt-timestamp.
5. Импортировать некорректный JSON — текущие настройки не меняются.
6. Импортировать схему 2.1 с общим IntervalMs.

## 12. Overlay

1. OFF/LMB/RMB/BOTH.
2. Compact/Extended.
3. Масштаб 70/100/160%.
4. Прозрачность 35/84/100%.
5. Все четыре угла.
6. Edit position: overlay принимает drag.
7. Завершить Esc: overlay снова click-through.
8. Кликнуть через overlay в игру.
9. Проверить Alt+Tab — overlay не появляется в списке.

## 13. Multi-monitor overlay

1. Мониторы с разным DPI и координатами, включая отрицательные.
2. Перенести активную игру на каждый монитор.
3. Overlay следует за foreground monitor.
4. Custom offset сохраняется относительно монитора.
5. Corner position не использует WorkArea и не прыгает от taskbar.

## 14. Minecraft borderless

1. Minecraft Java в fullscreen.
2. Получить один premium prompt.
3. Разрешить и проверить borderless.
4. Проверить overlay, ввод и Alt+Tab.
5. Отключить overlay и проверить восстановление.
6. Повторить — вопрос не показывается.
7. Сбросить consent и проверить повторный вопрос.
8. Повторить для Bedrock.
9. Выбрать «Не разрешать» и убедиться, что окно не меняется.
10. Проверить, что после подтверждения F11 попадает именно в Minecraft, а HUD остаётся поверх borderless-окна.

## 15. Quality of Life

1. Startup on/off в HKCU.
2. Start minimized.
3. Minimize to tray.
4. Open/Panic/Exit из tray.
5. Close behaviors: tray/exit/ask.
6. Portable settings рядом с EXE.
7. Installed settings в LocalAppData.
8. Экспорт обезличенной диагностики.

## 16. GitHub Releases

1. Проверить фиксированный источник `netrox336-ops/AutoClickerMinecraft`.
2. Репозиторий без более новой версии возвращает «актуальная версия».
3. Репозиторий с более новой версией показывает предложение обновления.
4. Отключить update check.
5. Проверить тихое tray-уведомление.

## Release acceptance

- self-test = 0;
- нет зависших кнопок;
- нет navigation/repaint дефектов;
- нет белых WPF-контролов;
- LMB/RMB проходят 30-минутный совместный тест;
- настройки восстанавливаются после повреждения;
- Minecraft восстанавливается после завершения;
- ZIP не содержит bin/obj/build/dist, secrets или абсолютных путей.
