# Auto Clicker Design System 3.0

## Принципы

1. Продукт выглядит как единая система, а не набор стандартных Windows-контролов.
2. Красный или выбранный accent обозначает действие и активность, но не используется как декоративный шум.
3. Состояние канала видно без чтения: Ready, Active, CPS, физически нажатый хоткей.
4. Отступы кратны 4 px; основные шаги — 8, 12, 16, 18, 22, 30.
5. Анимация объясняет изменение и никогда не влияет на click-worker.
6. Reduced Motion превращает переходы в мгновенные.

## Геометрия

| Элемент | Радиус |
|---|---:|
| главное окно | 18 px |
| карточка | 16 px |
| overlay | 15 px |
| кнопка/input | 9–10 px |
| status badge | 9 px |

Минимальная интерактивная высота — 40 px. Карточка использует внутренний отступ 22 px, расстояние между крупными карточками — 18 px.

## Типографика

- Segoe UI Variable Text с fallback Segoe UI;
- заголовок страницы: 24 px / SemiBold;
- заголовок карточки: 11–13 px / Bold;
- значение: 18–22 px / SemiBold;
- основной текст: 12–13 px;
- служебная подпись: 9–11 px.

## Motion

| Событие | Время |
|---|---:|
| hover scale | 120 мс |
| toggle thumb | 160 мс |
| page fade/slide | 180–210 мс |
| overlay show/hide | 140–180 мс |
| numeric fade | 110 мс |

Анимации используют transform/opacity и не вызывают layout в click-loop.

## Mica/Acrylic

Windows 11 получает `DWMSBT_MAINWINDOW`, immersive dark mode и DWM rounded corners. Ползунок прозрачности меняет alpha угольно-чёрной surface-подложки `72–100%`, сохраняя контраст текста.

## Иконки

Внутренние иконки — локальные WPF Geometry на основе Material Symbols. В рантайме нет web-font, HTTP-запроса или зависимости от установленного шрифта.

Приложение использует отдельный ICO с кадрами `16/24/32/48/64/128/256`, построенный из утверждённой пользовательской иконки.

## Overlay

Compact показывает состояние, суммарный CPS и оба интервала. Extended показывает CPS каждого канала отдельно. Любая новая строка должна помогать принять решение во время игры; прочая информация остаётся в главном окне.
