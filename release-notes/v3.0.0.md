# Auto Clicker 3.0.0

Полноценный продуктовый выпуск для Windows 11.

- полностью новый WPF-интерфейс и премиальная дизайн-система;
- два независимых click-worker и разные интервалы LMB/RMB;
- Panic Key и гарантированный отпуск кнопок;
- Hotkey Studio;
- click-through/no-activate overlay;
- Minecraft borderless workflow без внедрения в игру;
- Mica/Acrylic, темы, DPI 100–200%;
- трей, portable-режим, установщик, восстановление JSON и обновления.

Архив релиза содержит исходники версии 3.0.0.
