# Auto Clicker 3.0.1

Полноценный двухканальный автокликер для Windows 11. LMB и RMB имеют собственные глобальные хоткеи, режимы срабатывания и интервалы `1–1000 мс`, поэтому могут работать независимо и одновременно.

## Главное

- `Mouse 4 / Hold → LMB` по умолчанию;
- `Mouse 5 / Hold → RMB` по умолчанию;
- отдельные интервалы LMB и RMB;
- режимы `Hold`, `Toggle`, `Press` для каждого канала;
- Panic Key `F12`;
- клавиатурные сочетания и Mouse 3/4/5;
- работа при зажатых `W + Space + Shift`;
- события хоткеев всегда передаются в игру;
- фактический CPS по событиям, принятым `SendInput`;
- премиальный WPF-интерфейс с Mica/Acrylic;
- пять акцентных тем;
- Per-Monitor DPI V2;
- игровой click-through/no-activate overlay;
- запоминаемый Minecraft borderless workflow;
- portable и installed режимы;
- обновления через GitHub Releases;
- встроенный self-test.

В приложении нет Ultra, Burst, Double/Triple Click, Random Interval, макросов или средств обхода античита.

## Быстрый запуск

1. Полностью распакуйте исходный ZIP.
2. Запустите `install-and-build.bat`.
3. Скрипт при необходимости установит .NET 8 SDK и Inno Setup через `winget`.
4. Проект будет опубликован как автономный Windows x64 EXE.
5. Перед упаковкой автоматически выполнится `AutoClicker.exe --self-test`.

Результаты:

- portable EXE: `dist\AutoClicker-v3.0.1-Win11-x64\AutoClicker.exe`;
- portable ZIP: `dist\AutoClicker-v3.0.1-Windows-x64-portable.zip`;
- установщик: `dist\AutoClicker-v3.0.1-Setup.exe`.

Если зависимости уже установлены, используйте `build-only.bat`.

## Управление

| Канал | Хоткей | Режим | Интервал |
|---|---|---|---|
| LMB | Mouse 4 | Hold | 50 мс |
| RMB | Mouse 5 | Hold | 50 мс |
| Emergency Stop | F12 | Press | — |

Интервалы LMB и RMB полностью независимы. Например, можно установить LMB `10 мс`, RMB `3 мс`, удерживать Mouse 4 и Mouse 5 одновременно, а затем отпустить только один канал.

### Режимы хоткея

- `Hold` — канал работает, пока основной биндинг физически удерживается;
- `Toggle` — первое нажатие запускает канал, второе останавливает;
- `Press` — одно физическое нажатие отправляет ровно один клик.

Повтор клавиатуры и повторные mouse-down от драйвера не создают повторного запуска. При пропущенном release приложение сверяется с `GetAsyncKeyState` и завершает Hold.

## Panic и безопасная остановка

Panic Key:

1. инвалидирует поколения обоих worker;
2. устанавливает оба stop-сигнала;
3. немедленно отправляет LMB/RMB button-up;
4. ожидает завершение потоков;
5. повторно отправляет button-up;
6. очищает активные состояния глобального hook.

Тот же release-path используется при обычной остановке, блокировке Windows и завершении приложения.

## Hotkey Studio

- захват клавиатуры, Mouse 3, Mouse 4 и Mouse 5;
- сочетания `Ctrl/Alt/Shift/Win + клавиша/мышь`;
- независимый режим LMB/RMB без блокировки исходных событий;
- проверка бинда без запуска кликов;
- обнаружение конфликтов;
- смена LMB/RMB местами вместе с интервалами;
- подтверждение состояния keyboard/mouse hook.

В совместимом режиме лишние зажатые клавиши игнорируются: Mouse 4/5 продолжают работать при `W + Space + Shift`.

## Overlay

Overlay показывает:

- `OFF`, `LMB`, `RMB` или `BOTH`;
- фактический CPS отдельно для каналов;
- интервалы LMB и RMB;
- компактное или расширенное представление.

Настраиваются:

- размер `70–160%`;
- прозрачность `35–100%`;
- четыре угла;
- произвольная позиция мышью;
- автоматический переход на активный монитор.

В обычном режиме окно использует `WS_EX_TRANSPARENT`, `WS_EX_NOACTIVATE`, `WS_EX_TOOLWINDOW` и `TOPMOST`. Оно не получает фокус и не забирает мышь. Для перетаскивания click-through временно снимается и восстанавливается после нажатия «Готово» или `Esc`.

## Minecraft fullscreen

Обычное внешнее top-level окно нельзя гарантированно отобразить поверх настоящего exclusive fullscreen без внедрения в процесс. Auto Clicker этого не делает.

Вместо этого приложение:

1. обнаруживает fullscreen Minecraft Java/Bedrock;
2. один раз спрашивает разрешение;
3. запоминает ответ;
4. пользовательским F11-запросом возвращает игру под Windows compositor;
5. применяет borderless-стиль на исходном мониторе и разрешении;
6. восстанавливает исходные style, placement и fullscreen при отключении overlay или выходе.

Нет DLL-инъекции, чтения памяти игры, вмешательства в рендер или сокрытия от античита.

## Настройки и восстановление

Installed mode: `%LOCALAPPDATA%\AutoClicker\settings.json`

Portable mode: `data\settings.json` рядом с EXE.

Сохранение выполняется через временный файл, принудительный flush и атомарную замену с `.bak`. Повреждённый JSON переносится в файл `.corrupt-<timestamp>`, после чего загружается backup или безопасная стандартная конфигурация.

Настройки 2.0/2.1 мигрируются:

- общий интервал переносится в LMB и RMB;
- устаревшие флаги подавления безопасно игнорируются;
- старые хоткеи и Toggle/Hold/Press сохраняются;
- удалённые Ultra/Burst/Random-поля игнорируются.

## Диагностика и приватность

Экспортируемый отчёт содержит версию Windows/.NET, архитектуру, состояние hook, режим хранения, интервалы, режимы, отображаемые имена биндов и счётчики текущей сессии.

Он не содержит имя пользователя, пути профиля, координаты курсора, список программ или содержимое игровых окон.

## Ограничения

- `SendInput` может быть заблокирован игрой, запущенной с более высокими правами;
- если игра запущена администратором, Auto Clicker также нужно запустить администратором;
- правила игры или сервера могут запрещать автокликеры;
- отдельные драйверы мыши могут преобразовывать Mouse 4/5 в клавиатурные события — в таком случае назначьте фактически получаемую клавишу через Hotkey Studio.

Используйте приложение только там, где автоматизация разрешена.
