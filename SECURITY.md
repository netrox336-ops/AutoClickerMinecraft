# Безопасность

## Поддерживаемая версия

Исправления безопасности выпускаются для последней опубликованной версии Auto Clicker.

## Границы проекта

Auto Clicker использует публичные Win32 API, `SendInput`, глобальные low-level hooks и внешний overlay через Windows compositor. Проект не использует DLL-инъекцию, чтение памяти Minecraft, вмешательство в рендер или механизмы сокрытия от античита.

## Как сообщить о проблеме

Не публикуйте рабочий эксплойт и личные данные в открытой задаче. Создайте краткую задачу без чувствительных деталей и попросите владельца репозитория предоставить безопасный канал связи.
